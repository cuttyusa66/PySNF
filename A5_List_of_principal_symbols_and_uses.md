## Quick-Lookup Index (Alphabetical, by Category)

### Wave-Coefficient Family
- **Incoming:** $a_{smn} = Q^{(4)}_{smn}$ (single-index: $a_j$); column matrix $\mathbf{a}$.
- **Outgoing:** $b_{smn} = Q^{(3)}_{smn}$ (single-index: $b_j$); column matrix $\mathbf{b}$.
- **General:** $Q^{(c)}_{smn}$ — $c = 3$ outgoing, $c = 4$ incoming.

### Antenna Scattering / Network Coefficients
- **Receiving:** $R_{smn}$ ($R_j$, row matrix $\mathbf{R}$).
- **Transmitting:** $T_{smn}$ ($T_i$, column matrix $\mathbf{T}$).
- **Scattering matrix:** $S^{\sigma\mu\nu}_{smn}$ ($S_{ij}$, matrix $\mathbf{S}$).
- **Probe response constant:** $P^{\sigma}_{s\mu n}$.

### Special Functions (Spherical Wave Expansion)
- $j_n(kr)$ — spherical Bessel.
- $h^{(1)}_n(kr)$ — spherical Hankel (first kind).
- $R^{(c)}_{sn}(kr)$ — radial function ($c$ selects $j_n$, $h^{(1)}_n$, etc.).
- $P^{m}_n(\cos\theta)$ — associated Legendre; $\bar{P}^{m}_n$ — normalized.
- $d^{n}_{\mu m}(\theta)$ — rotation coefficient; $\Delta^{n}_{\mu m} = d^{n}_{\mu m}(\pi/2)$.
- $\vec{F}^{(c)}_{smn}$ — spherical vector wave function.
- $\vec{K}_{smn}$ — far-field pattern function; $\vec{K}(\theta,\phi)$ — far-field pattern.
- $C^{sn(3)}_{\sigma\mu\nu}(kA)$ — translation coefficient.

### Field / Power Quantities
- $\vec{E}, \vec{H}$ — fields; $\vec{F}$ — combined field vector.
- $\vec{J}, \vec{M}$ — volume current densities; subscript $s$ = surface; superscripts $u, v, w, L$ — symmetric, antisymmetric, image, sampled.
- $\vec{S}$ — Poynting's complex vector.
- $P_{\text{rad}}$ — radiated power; $\{P^n_{\text{rad}}\}$ — power spectrum.
- $D(\theta,\phi)$ — directivity; $G(\theta,\phi)$ — gain.

### Geometry / Measurement
- $A$ — measurement distance; $r_0$ — minimum-sphere radius.
- $\hat{n}$ — surface normal; $S$ — surface; $V$ — volume.
- $\hat{i}_{co}, \hat{i}_{\text{cross}}$ — copolar / cross-polar unit vectors.
- $(\chi_o, \theta_o, \phi_o)$ — Euler angles; $\phi_r$ — repetition angle.

### Indices and Limits
- $s, m, n$ — primary spherical-mode indices.
- $i, j$ — single-index convention; limits $J$ (for $i, j$), $N, M$ (for $n, m$).
- $\sigma, \mu, \nu$ — additional mode indices.
- $L$ — number of probes/samples; $N_r$ — number of repetitions.

### Constants and Medium Properties
- $k = 2\pi/\lambda$ — free-space propagation constant; $\vec{k}_o$ — plane-wave propagation vector.
- $\lambda$ — wavelength; $\omega$ — angular frequency.
- $\varepsilon, \mu$ — permittivity, permeability; $\zeta, \eta$ — specific impedance, admittance.
- $\Gamma$ — reflection coefficient.
- $\exp(-i\omega t)$ — assumed (suppressed) time convention.

### Error / Spectral Analysis
- $u_n$ — element of spherical wave error spectrum.
- $T(\vec{r})$ — relative plane-wave deviation; $T_{\max}(r)$ — its spherical profile.
- $\vec{P}(k_x, k_y, z)$ — plane-wave spectrum.

### Probe Signals
- $v, v_p$ — input waves to test antenna / probe.
- $w, w_t$ — output waves at probe / test antenna (receiving).
- $W(\chi, \theta, \phi), W'(\chi, \theta, \phi)$ — normalized far-field input/output probe signals.
- $\mathbf{W}$ — matrix of transformation weights.
